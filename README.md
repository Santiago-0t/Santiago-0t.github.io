# santiago-0t.github.io

Personal portfolio of Santiago Otalvaro Ortega, served with GitHub Pages.

Static site with no build step: `index.html`, `styles.css`, `main.js`.

- Palette: Zenwritten (dark by default, light variant via system preference or the theme toggle).
- Fonts: Fraunces, Space Grotesk, Space Mono and Noto Sans JP (Google Fonts).

To preview locally, open `index.html` in a browser.
